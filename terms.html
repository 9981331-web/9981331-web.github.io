Nexus Mail

Личное приложение владельца почтового ящика. Читает Gmail, определяет письма с поручениями и создаёт локальные задачи в Nexus Plan. Пересланная из Яндекса почта обрабатывается в Gmail.

Политика конфиденциальности · Условия использования

Политика конфиденциальности

Приложение использует единственное разрешение Gmail: чтение почты (gmail.readonly). Оно получает отправителя, тему, дату, текст и оригинальные вложения. Приложение не отправляет и не удаляет письма, не меняет метки и статус прочтения.

Текст выбранных писем передаётся OpenAI через официальный Codex CLI, авторизованный владельцем, для определения необходимых действий. Перед анализом удаляются ссылки и распознаваемые шаблоны секретов; автоматическое распознавание не гарантирует удаления любых секретов из произвольного текста. Вложения в модель не передаются. Они сохраняются локально в личном хранилище Obsidian; если владелец синхронизирует его через OneDrive, синхронизация выполняется этим сервисом.

OAuth-токены хранятся на компьютере в LocalAppData, зашифрованы Windows DPAPI для текущего пользователя. Токены не передаются модели. Локальный журнал хранит результаты классификации, даты, Gmail ID и связи с задачами. Задачи и сводки находятся в локальной базе Nexus Plan. Данные почты не продаются, не используются приложением для рекламы или обучения собственных моделей. Использование данных Google ограничено заявленными функциями и требованиями Google API Services User Data Policy, включая Limited Use.

Владелец может выключить задание Windows, отозвать доступ в настройках Google-аккаунта и удалить локальный журнал, токены, файлы и задачи. Автоматическое удаление пользовательских данных приложением не производится. Контакт: адрес поддержки, указанный на экране согласия Google.

Условия использования

Приложение предназначено для личного использования владельцем. ИИ-классификация и извлечённые сроки могут содержать ошибки и требуют оценки пользователем. Приложение не выполняет указания из писем, не открывает файлы и не заменяет проверку официальных источников. Локальное расписание работает при включённом компьютере и активном входе пользователя Windows. Доступ к почте и модели зависит от доступности соответствующих сервисов.
